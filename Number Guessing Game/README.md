# Java Number Guessing Game 🎮

## 📌 Project Description

This is a simple **Java console game** where the computer generates a random number between **1 and 100**.
The player must guess the number. The program gives hints such as **"Too High"** or **"Too Low"** until the correct number is guessed.

This project is created to practice basic **Java programming concepts**.

---

## 🚀 Features

* Random number generation
* User input using Scanner
* Hints for the player

  * Too High
  * Too Low
* Loop until the correct guess
* Simple console-based interface

---

## 🧠 Concepts Used

* Java `Random` class
* `Scanner` class
* `while` loop
* `if-else` conditions

---

# Java Simple Calculator

## 📌 Project Description

This project is a **simple calculator application written in Java**.
It allows users to enter two numbers and select a mathematical operator to perform calculations.

The program uses a **method and switch statement** to handle different operations and display the result.

## 🚀 Features

* Perform basic arithmetic operations
* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Handles divide-by-zero errors
* Simple console-based user input

## 🛠 Technologies Used

* Java
* Scanner Class
* Methods
* Switch Statement

## 📂 Project Structure

Cal.java – Main Java program file

## ▶ How to Run the Program

1. Compile the Java file

```
javac Cal.java
```

2. Run the program

```
java Cal
```

3. Enter the required inputs when prompted.

## 💻 Example Output

```
Enter Number 1: 12
Enter Number 2: 4
Enter Operator(+,-,*,/): /

Result = 3.0
```
